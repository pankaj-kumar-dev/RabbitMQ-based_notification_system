Distributed Notification System

Event-driven notification pipeline built on the Transactional Outbox pattern. Guarantees at-least-once delivery from API ingestion through RabbitMQ to partitioned consumers, with Redis-backed idempotency and a TTL-based cascading retry chain terminating in a dead-letter queue.
